# **רמת הקושי**

היעד הוא רמה שמתאימה למבחן האמיתי.

השתמש ב:

- Distractors שנשמעים הגיוניים.
- Scenarios ארוכים כאשר זה מתאים.
- כמה דרישות בו-זמנית.
- שאלות שבהן יותר מאפשרות אחת technically works אבל רק אחת היא **BEST**.
- ניסוחים כמו:
    - MOST cost-effective
    - MOST scalable
    - LEAST operational overhead
    - MOST secure
    - BEST solution
    - MOST highly available
    - MINIMUM changes
    - WITHOUT managing servers

אבל אל תשתמש בטריקים מלאכותיים או ניסוח מבלבל רק כדי להקשות.

# **כלל חשוב במיוחד**

אני רוצה ללמוד **איך AWS חושבים**.

לכן אחרי כל טעות הסבר לי לא רק:

“מה נכון”

אלא:

**איזו מילה או דרישה ב-Scenario הייתה אמורה להוביל אותי לתשובה?**

לדוגמה:

“least operational overhead”  
→ העדפה לשירות מנוהל/serverless.

“must survive AZ failure”  
→ Multi-AZ.

“global users + low latency”  
→ CloudFront / Global architecture.

“decouple application components”  
→ SQS/SNS/EventBridge בהתאם ל-use case.
